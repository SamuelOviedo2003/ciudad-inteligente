# Sistemas conectados

[Diapositivas](../clase/sistemas-conectados.md)
[PDF](../clase/sistemas-conectados.md)
Trabajaremos los siguientes puntos durante la clase:
- La implementación de Máquinas de Estados Finitos (MEF) en Arduino se basa en el uso del tiempo relativo, calculado con millis() y micros(), lo que permite controlar secuencias temporizadas en proyectos de sistemas conectados.
- El código para una MEF en Arduino se organiza con estructuras switch-case dentro del bucle loop(), permitiendo definir y gestionar diferentes estados del sistema.
- Se presentan ejemplos de MEF como el parpadeo de un LED, una MEF de seguridad de batería y una variante de parpadeo en código SOS cuando la batería está baja.
- Se detalla la construcción de una estación meteorológica IoT con sensores y comunicación inalámbrica, que envía datos a la nube a través de una plataforma como Ubidots.
- También se describe un taller para una estación meteorológica autoadaptable con sistemas maestro y esclavo, que actúa ante condiciones extremas de temperatura y envía alertas a la nube.

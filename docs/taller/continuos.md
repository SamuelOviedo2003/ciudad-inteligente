Trabajaremos los siguientes puntos durante la clase:
- La retroalimentación en sistemas dinámicos permite ajustar la respuesta de un sistema ante cambios y mejorar su robustez, con aplicaciones destacadas en el control de velocidad de vehículos y sistemas de vuelo.
- La dinámica de un sistema describe la relación entre sus entradas y salidas, y se representa mediante funciones de transferencia y diagramas de bloques para analizar su comportamiento.
- Para modelar la dinámica de un sistema, se emplean ecuaciones diferenciales y la transformada de Laplace, con ejemplos prácticos como el sistema masa-resorte-amortiguador.
- Se explica el proceso de modelado experimental en un sistema de iluminación controlado por Arduino, desde la recolección de datos hasta la optimización de la función de transferencia del modelo.
- Finalmente, se introduce el diseño de un controlador PI para el sistema de iluminación, detallando la sintonización y optimización de sus parámetros para mejorar su desempeño.
